Instagram Backend

Manual de Configuração - API de Posts do Instagram

🚀 Bem-vindo

Este é um backend para integração com a API do Instagram Graph que permite buscar posts de um usuário. Para funcionar, você precisará configurar credenciais válidas da Meta/Instagram.

📋 Pré-requisitos

  • Conta Meta/Facebook ativa
  • Conta Instagram Business ou Creator
  • Acesso ao Meta App Dashboard

🔧 Passo a Passo

1. Acessar Meta App Dashboard

Acesse https://developers.facebook.com/apps e faça login com sua conta Meta.

2. Criar uma Nova Aplicação

Clique em "Criar Aplicação" e selecione o tipo "Negócio" (Business). Preencha as informações básicas.

3. Adicionar Produto Instagram Graph API

Na dashboard da aplicação, procure por "Instagram Graph API" e clique em "Configurar" ou "Adicionar Produto".

4. Obter Token de Acesso

Vá para Ferramentas → Explorador de Gráficos. Selecione sua versão da API e clique em "Gerar Token de Acesso". Você pode:

  • Usar um token de teste (temporário)
  • Gerar um token de usuário (permanente com renovação)
  • Gerar um token de aplicação
5. Obter o ID do Usuário/Conta

No Explorador de Gráficos, execute a query:

GET /me

Você receberá um JSON com seu ID. Copie o valor do campo "id".

6. Configurar Variáveis de Ambiente

Crie um arquivo .env na raiz do projeto com:

INSTAGRAM_API_URL=https://graph.instagram.com/v18.0 INSTAGRAM_ACCESS_TOKEN=seu_token_aqui INSTAGRAM_USER_ID=seu_id_aqui PORT=3000
⚠️ Importante: Nunca compartilhe seu token. Mantenha o arquivo .env seguro e adicione-o ao .gitignore.
7. Buscar Posts

Use a query no Explorador de Gráficos para testar antes:

GET /me/media?fields=id,caption,media_type,media_url,timestamp

📡 Endpoints Disponíveis

GET /health

Verifica se o servidor está funcionando.

Resposta:

{"status":"ok"}
GET /posts

Retorna os posts do usuário Instagram configurado.

Resposta (sucesso):

{ "data": [ { "id": "123456", "caption": "Meu post", "media_type": "IMAGE", "media_url": "https://...", "timestamp": "2024-01-01T12:00:00+0000" } ] }

🔍 Solução de Problemas

Erro 401 - Token inválido

O token pode ter expirado. Gere um novo no Meta App Dashboard.

Erro 400 - Bad Request

Verifique se o ID do usuário está correto e se sua conta está vinculada corretamente.

Erro 403 - Permissão negada

Sua conta pode não ter permissão de Business. Configure sua conta para Business Account ou Creator Account.

Cannot GET / (após deploy)

Significa que o servidor está rodando, mas há um "Cannot GET /" - isso é normal! Use os endpoints corretos como /health e /posts.

✅ Checklist de Deploy

  • Token de acesso obtido e testado
  • ID do usuário/conta configurado
  • Arquivo .env criado com as variáveis
  • Endpoint /health respondendo 200 OK
  • Endpoint /posts buscando dados corretamente
  • .env adicionado ao .gitignore
  • Docker Compose configurado e container rodando
✨ Pronto! Seu backend está configurado e pronto para uso. Acesse os endpoints acima para começar a integração.
